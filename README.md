# Raksha Bandhan Surprise

A simple, static Raksha Bandhan surprise page made for Kuku. Open `index.html` directly, or upload the whole folder to any static host.

## Personalize

Edit the `config` object at the top of `script.js` to change the brother's name, message, photo path, video path, or music path. The starter photo and video poster are placeholders in `assets/`; replace them with your own media and keep the configured filenames, or update the paths.

The page has no build step or dependencies. Background music begins only after the first surprise button click, and the music toggle remains available in the top-right corner.
